Latest accepted report: [92 formal trials + separate cached98](https://asimfish.github.io/psibot-astra-experiments/snapshots/frontier-92/). The repository root page remains the historical snapshot of 53 trials described below.

This report presents a fixed snapshot of 53 accepted native simulation trials and 472 completed Astra model responses, as of 2026-10-12 18:30 UTC. The goal is 1,000 trials across four tasks and 50 input conditions. Every condition requires at least 20 matched seeds; no condition or paired contrast is complete in this snapshot. Success counts and timing summaries are descriptive, with no causal input-effect claim.

Each task and condition groups the actual camera inputs, same-episode original videos, physical outcome, physical pickup retries, and wall/model timing. Execution environment accompanies each trial's timing. Initial empty history and previous-action channels are distinguished from deliberate removals. PsiBot uses five frozen hand presets with bounded refinement.

The historical 47-trial dashboard remains at https://asimfish.github.io/psibot-dashboard/astra.html. This lightweight repository contains 54 incremental byte-preserved original media files; 350 same-SHA originals reuse that dashboard's public URLs. `media-manifest.json` records every original SHA, size and URL. No video is reencoded. Later accepted trials, infrastructure failures, and cached-offset qualification runs are outside this fixed snapshot.
